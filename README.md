# VerseMatch ✝️

VerseMatch is a Streamlit app where you write about what you're experiencing and receive a Bible verse matched to the general themes in your message.

## Features

- Write about your day or feelings
- Automatically detects broad themes
- Suggests a fitting Bible verse
- Clean, peaceful interface
- Runs directly in a web browser

## Run locally

Install the requirements:

```bash
pip install -r requirements.txt
